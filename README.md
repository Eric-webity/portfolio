# Portfólio de UI e Web Design

Site pessoal com estudos de interface e front-end: layout, navegação e páginas de apresentação, projetos e contato. Feito em HTML, CSS e JavaScript.

Publicado em https://eric-webity.github.io/portfolio/

## Páginas

- `index.html`: início
- `sobre.html`: apresentação
- `projetos.html`: trabalhos
- `contato.html`: contato

## Como abrir

Abra `index.html` no navegador ou acesse o endereço publicado acima.
